The launcher that stays out of the way.

Kaldrix Launcher manages Minecraft: Java Edition versions, instances and mods on Windows. The installer is under 3 MB.

Download coming soonThe launcher is in development. Playing will require an account that owns Minecraft: Java Edition.

What it does

Separate instances

Each instance has its own game version, memory and mods.

Mods with dependencies

Search by name, recognise the mod by its icon and install the ones it requires too. If one is missing, it tells you.

Verified files

Game files and mods are downloaded over HTTPS only and checked against their hash.

Automatic Java

Finds the right Java on your PC, or downloads the one you need.

Official Microsoft sign-in

Your password is entered only on Microsoft's website. Kaldrix never sees it.

No telemetry

Kaldrix collects no statistics about how you play.
